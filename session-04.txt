vim editor
===========

colon mode
==========
:wq -> write and quit
:q -> quit
:q! -> force quit
:set nu
:set nonu
:<line-number> cursor will take us that line number
/<word-to-search> -> forward search
?<word-to-search> -> backward search
:2d -> delete 2nd line
:5,10d -> delete 5th to 10th lines
:%d -> delete entire content
:noh -> dont highlight the word
:3s/<word-to-find>/<replacing-word> -> by default first occurence in line number 3
:3s/sbin/SBIN/g -> all occurences in line number 3
:%s/sbin/SBIN -> entire file, all rows first occurence
:%s/sbin/SBIN/g -> all rows all occurences

Esc Mode
========
gg -> you will be taken to top of the file
Shift+g -> bottom of the file
u -> undo
Ctrl+r -> redo
yy -> copy that line
p -> paste that line
10p -> paste that line 10times

Insert mode
==========
i

User management
====================
$ -> normal user
# -> root user
/root -> root user home folder
/home/<user-name>
/home/ec2-user

User -> Human
Group -> A list of humans, A group will have more users

Authentication(Prove yourself) and Authorization(Do you have access to this resource)

Authorization
==============
Role 	-> Permissions

Trainee -> Read only access
Junior	-> Write access
Senior 	-> Read, Write and Update access
TL		-> Read, Write, Update and Delete access

A group will have role -> Permissions

ramesh -> devops-trainees
devops-juniors
devops-serniors
devops-lead

useradd <user-name>
when we create user, linux will create a group also on the same user name
A user in linux will have 1 primary group and 0 or more secondary groups
userid 0 means, it is root user

/etc/passwd -> user info
/etc/group -> group info
groupadd sre -> creating group <sre is group name>
usermod -g <group-name> <user-name> -> adding user to primary group
usermod -g devops ramesh

usermod -aG sre ramesh

passwd <user-name> -> set the password to user

/etc/ssh/sshd_config -> ssh config
sshd -t -> check syntax of ssh config
systemctl restart sshd

Permissions
============
R -> 4
W -> 2
X -> 1

-rw-r--r--
- -> file
only owner or root user can only change the permissions to the file
u			g			o
Owner		Group		Others
rw-			r--			r--

chmod u+x devops.txt

u -> RWX
g -> RX
o -> X

chmod 751 devops.txt

ownership
===========
a file ownership can only be changed by root user, not even owner of the file
chown user:group <file>
chown user:group -R <folder>
